# Interface design

SDM serves desktop operators comparing provenance and runtime evidence. Keep service, environment, instance and observation time visible before technical detail.

Use the repository-local UI tokens, typography, icons and themes. Preserve Mono, Cobalt and Orange palettes independently from light/dark/system mode. Unknown state is neutral. Status always includes text or shape in addition to color.

Keep catalog, overview, map, history and source diagnostics consistent. The map's amber selection highlights one supported relationship path. Category color, line style and labels retain resource/relationship meaning. Respect reduced motion.

Background updates preserve selection, route context and scroll position. Failures retain a prior snapshot when available and explain its age. Keyboard controls and visible focus must work for navigation, resource search, dialogs and graph actions.

Mobile layout is not a supported product scope in this version.
